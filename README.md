# Лабораторна робота №3: Інтерактивний Web-додаток
**Розробка клієнтської частини на Vue.js та інтеграція з REST API**

## Інформація про студента
- **ПІБ:** Іваха Богдан Миколайович[cite: 1]
- **Група:** КВ-32[cite: 1]

## Завдання
1. Ознайомитись із принципами роботи JavaScript-фреймворку **Vue.js**[cite: 1].
2. Реалізувати реактивний інтерфейс користувача з використанням компонентного підходу[cite: 1].
3. Налаштувати асинхронну взаємодію з сервером через **Fetch API**[cite: 1].
4. Забезпечити збереження та відображення даних (пости, коментарі) за допомогою зв'язки **Node.js + SQLite**[cite: 1].
5. Тематика додатка: **Блог з коментарями**[cite: 1].

## Технологічний стек
* **Frontend:** Vue.js, Tailwind CSS[cite: 1].
* **Backend:** Node.js, Express.js[cite: 1].
* **Database:** SQLite[cite: 1].
* **Інструменти:** Fetch API для запитів, LocalStorage для зберігання сесії[cite: 1].
